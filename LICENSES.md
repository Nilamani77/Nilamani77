# Embedded asset licenses

## Noto Sans / Noto Mono
The embedded `NotoSans-Black.woff2` and `NotoMono-Regular.woff2` fonts are from the Noto font family and are distributed under the SIL Open Font License 1.1.

Source: https://github.com/notofonts/noto-fonts
License text: https://openfontlicense.org/

The SVGs embed the converted WOFF2 data directly so they make no network requests.

## Icons
The stack uses compact typographic labels rather than externally loaded icon files. No third-party icon asset is fetched at runtime.
